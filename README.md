# Калькулятор устойчивости откосов (Gravey)

Десктопное приложение для расчета устойчивости грунтовых сооружений методом предельного равновесия и методом конечных элементов (МКЭ).

## Описание проекта

Программное обеспечение предназначено для инженерных расчетов устойчивости откосов и склонов. Позволяет моделировать геометрию откоса, задавать слоистую структуру грунта, учитывать уровень грунтовых вод и выполнять расчет коэффициента запаса устойчивости (FS) различными методами.

**Проект разработан в рамках дипломной работы** по направлению 09.03.02 "Информационные системы и технологии".

## Основные возможности

- **Рисование контура откоса** любой формы с помощью мыши
- **Многослойная модель грунта** с индивидуальными физико-механическими свойствами
- **Учет уровня грунтовых вод (УГВ)** с автоматическим снижением прочностных характеристик
- **4 метода расчета устойчивости:**
  - Метод Бишопа (упрощенный) — по СП 11-105-97
  - Метод Янбу
  - Метод Моргенштерна-Прайса
  - Метод конечных элементов (МКЭ/FEM) — метод редукции прочности
- **Автоматический поиск критической поверхности скольжения**
- **Модуль фильтрации** на основе закона Дарси и МКЭ
- **Визуализация результатов:** кривые обрушения, векторные поля скоростей фильтрации, линии тока
- **Экспорт отчетов** в текстовые файлы и таблицы CSV
- **Управление проектами:** сохранение/загрузка в формате JSON

## Технические требования

- **Python:** 3.12+
- **Операционная система:** Windows 10/11, Linux, macOS
- **GUI:** tkinter (встроен в Python)
