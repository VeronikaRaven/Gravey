# Геотехнический калькулятор

Приложение на Python и Tkinter с вкладками устойчивости откоса,
фильтрации и промерзания/оттаивания. Сторонние Python-пакеты не нужны.
В установленном Python должна быть поддержка Tcl/Tk.

## Запуск в Windows

В этой системе проверен Python 3.13:

```powershell
py -3.13 main.py
```

Команда `python main.py` в текущем окружении выбирает Python 3.12,
который завершается с ошибкой загрузки `init.tcl`. Для запуска из IDE
выберите интерпретатор `C:\Python313\python.exe`.

Левой кнопкой мыши задайте не менее трех точек контура откоса,
затем нажмите «РАССЧИТАТЬ FS». На других вкладках сначала нажмите
«Скопировать контур». Колесо мыши меняет масштаб, Ctrl+Z отменяет
изменение контура. Меню «Проект» сохраняет и загружает JSON.

Название и цвет основного грунта выбираются по ближайшему образцу;
в расчете используются введенные значения свойств.

## Проверки

```powershell
py -3.13 -m unittest discover -s tests -v
```

Проверки создают окна Tkinter, поэтому нужен графический сеанс.
Они проверяют запуск, выполнение расчетов, отрисовку, сохранение и
загрузку файлов. Точность инженерных моделей этими проверками не подтверждается.
